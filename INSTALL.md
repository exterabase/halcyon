# halcyon.

## Запуск

Из каталога проекта, под обычным пользователем, с Python 3.10+ и инструментами
сборки C (на Debian/Ubuntu: `build-essential`, `python3-dev`, `python3-venv`):

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --no-cache-dir -r requirements.txt
python -m halcyon --no-git
```

Создайте Telegram API ID и API hash на https://my.telegram.org. При первом старте
введите их и войдите в свой аккаунт. Для настройки встроенного бота следуйте
подсказкам программы. Храните файлы сессий, конфигурацию и резервные копии в
каталоге с доступом только для вашего пользователя.

В Docker запустите `bash docker.sh` для первого входа, затем
`docker compose up -d`. Используется именованный том `worker`.

## Команды

`.info` показывает сведения о текущем экземпляре. `.ping` измеряет время
запроса Telegram и выводит время работы. В `.config` у модулей
`halcyon. info` и `Tester` можно задать `banner_url`, положение предпросмотра
`invert_media` и оформление текста `quote_media`.

Сторонние модули запускаются в процессе userbot с его правами. Устанавливайте
модули из источников, которым доверяете. Для восстановления после проблем
с модулем используйте безопасную загрузку.
