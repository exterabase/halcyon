# halcyon.

## Запуск

Из каталога проекта, под обычным пользователем, с Python 3.10+ и инструментами
сборки C (на Debian/Ubuntu: `build-essential`, `python3-dev`, `python3-venv`):

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --no-cache-dir -r requirements.txt
python -m halcyon --no-git
```

Создайте Telegram API ID и API hash на https://my.telegram.org. При первом старте
введите их и войдите в свой аккаунт. Для настройки встроенного бота следуйте
подсказкам программы. Храните файлы сессий, конфигурацию и резервные копии в
каталоге с доступом только для вашего пользователя.

В Docker запустите `bash docker.sh` для первого входа, затем
`docker compose up -d`. Используется именованный том `worker`.

## Команды

`.info` показывает сведения о текущем экземпляре. `.ping` измеряет время
запроса Telegram и выводит время работы. В `.config` у модулей
`halcyon. info` и `Tester` можно задать `banner_url`, положение предпросмотра
`invert_media` и оформление текста `quote_media`.

Сторонние модули запускаются в процессе userbot с его правами. Устанавливайте
модули из источников, которым доверяете. Для восстановления после проблем
с модулем используйте безопасную загрузку.

## Android · UserLAnd · Ubuntu Minimal

Распакуйте архив в домашний каталог Ubuntu. При обновлении скопируйте
новые файлы поверх проекта, сохранив каталог `sessions/`, конфигурацию
`config*.json` и `.venv/`. Остановите старый процесс через Ctrl+C перед запуском.

```sh
cd ~/halcyon
HALCYON_MINIMAL=1 bash install.sh
```

Замените `~/halcyon` на фактический каталог проекта. Для первого запуска
установщику нужен `sudo` или root внутри Ubuntu. Android root не нужен.
Первый запуск собирает защитное расширение MTProto и может занять несколько минут.
Повторный запуск использует существующее виртуальное окружение.

Если BotFather уже создал бота, включите для него inline-режим через
`/setinline` и уведомления через `/setinlinefeedback`. Если токен где-либо
публиковался, отзовите его через `/revoke`. Затем запустите:

```sh
HALCYON_MINIMAL=1 bash install.sh --set-bot-token
```

Вставьте свежий токен в скрытый запрос терминала. Команда требует один
авторизованный аккаунт и сохраняет токен после авторизации бота. При
проблемах с инлайн-ботом команды Telegram-аккаунта остаются доступны.
